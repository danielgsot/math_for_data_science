# Mathematics for Data Science

A practical repository focused on reviewing and implementing the mathematical foundations behind Data Science and Machine Learning.

The goal of this project is to strengthen the theoretical concepts commonly used in Machine Learning while connecting them with practical implementations in Python and NumPy.

---

## Objectives

This repository focuses on understanding the mathematics behind Data Science rather than simply using high-level Machine Learning libraries.

The main objectives are:

- Review the mathematical foundations of Data Science
- Develop intuition behind important concepts
- Implement mathematical operations using Python and NumPy
- Connect theory with Machine Learning applications
- Build a strong foundation for more advanced ML topics
